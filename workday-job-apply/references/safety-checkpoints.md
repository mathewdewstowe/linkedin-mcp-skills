# Safety Checkpoints

## Always Confirm At Action Time

- Final application submission.
- Final Create Account action.
- Accepting terms/privacy consent checkboxes when they are required to submit an application.
- Uploading a resume/CV or other personal file unless the current user prompt already approved that exact file for that exact destination.

## Ask Before Filling

- Passwords or credentials for a new employer site.
- Salary expectations.
- Notice period.
- Work authorization, visa, sponsorship, or right-to-work answers.
- Criminal/background/safeguarding answers.
- Medical, disability, accommodation, demographic, or diversity fields.
- Gaps in employment/education.
- References or third-party personal data.

## Can Draft

- Role-specific motivation answers from the resume and job description, with user review before final submit.
- Neutral reason-for-leaving language if the user gives a minimal answer, but do not invent facts.
- Summaries of completed application fields, with sensitive values redacted unless needed for user review.
